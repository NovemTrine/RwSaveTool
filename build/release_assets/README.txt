RwSaveTool · 使用说明（v{version}）
============================================================

一、启动
------------------------------------------------------------
本包有两个 exe，任选一个双击即可，功能完全一样，无需安装、无需 Python：

  RwSaveTool.exe            目录版，启动快；必须和 _internal\ 文件夹放在一起
  RwSaveTool-onefile.exe    单文件版，可单独拷到别处；启动慢 1~3 秒

第一次启动，程序会在同一目录生成 config.json（默认配置）。
整个文件夹可以随意搬动或拷贝给别人，数据跟着走；
单文件版则跟着它自己所在的那个文件夹走。

如果放在 C:\Program Files 这类受保护目录，配置和导入缓存会
自动改存到 %APPDATA%\RwSaveTool\，不影响功能。

二、打开存档
------------------------------------------------------------
1. 启动后首页会列出检测到的存档槽位（sav / sav2 / sav3）。
2. 点任意一个槽位即可读取。
3. 存档默认位置：
   C:\Users\<你的用户名>\AppData\LocalLow\Videocult\Rain World\
4. 也可以把 sav 文件直接拖进窗口。

程序对存档是「只读」的：不会修改、不会另存、不会写回游戏目录。

三、区域数据与模组
------------------------------------------------------------
本包内置 {regions} 个官方区域的房间数据（原版 + Downpour + Watcher），
开箱即可看到区域完成度。

想统计创意工坊模组的区域，需要在程序里导入一次：

  工具栏 → 导入 → 选择创意工坊目录或模组文件夹
  也可以直接选游戏根目录，程序会自动找出官方几个包

导入结果会写进 region_data\，下次启动直接复用，不用重复导入。
模组文件夹被删除或更新后，界面会提示「有漂移」，重新导入即可。

v{version} 的区域数据格式为 schema 4（含每间房的出口编号与去向）。
用旧版程序打开本包的 region_data 会提示格式过旧，属预期。

四、区域地图与导出
------------------------------------------------------------
区域地图是按房间地形与门的连通关系现算出来的几何图，
不依赖游戏自带的地图图片，本包也不含任何游戏素材。

第一次打开某个区域会等 1~3 秒（大区域更久），同一区域再打开瞬间出图。
右侧清单里的房号与图上房间严格一致；没有地形文件的房间会单独列在
「无地形文件」一栏。

地图工具栏可导出 SVG / 2× PNG，拓扑图工具栏可导出高清 PNG。
导出会弹出系统「另存为」让你选保存位置；完成后右下角会写明完整路径，
并给一个「打开所在文件夹」。

五、界面速查
------------------------------------------------------------
总览          存档概况、角色、进度
区域          各区域完成度；可切换「严格 / 宽松」口径
             严格 = 只算当前角色能到的房间；宽松 = 算全部房间
区域地图      整区几何图 + 右侧房间清单（点房号定位、开卡）
房间卡        （在地图上点房间进入）单间房平面图 + 右侧出口清单
             · 每个出口有编号与目标房间名，点一行直接跳过去
             · 鼠标悬停某一行，画布上对应的管道口会亮起并显示编号
             · 默认全屏；按 F 或点「紧凑」可切回单栏
区域拓扑      把一间间房和门画成图，可拖动、缩放、定位房间
             · 单击节点进入房间卡，双击空白重新布局
击杀          击杀统计与分布环图
通行证        通行证解锁情况
全局解锁      跨存档的解锁汇总

六、自定义译名
------------------------------------------------------------
工具栏 → 译名。可以：
  · 逐条改中文名（留空 = 恢复内置译名）
  · 「批量翻译」：粘贴或读入 English|中文 的对照表，一次写入多条
    支持 # 或 // 注释、空行、全角竖线；自动跨分类匹配
    写入前会显示命中/跳过/未匹配的数量，需要点两次确认

译名只影响显示，不改存档、不改游戏文件。

七、常见问题
------------------------------------------------------------
Q: 双击没反应？
A: 若用的是 RwSaveTool.exe，确认 _internal 文件夹和它在一起（没解压完整）。
   或改用 RwSaveTool-onefile.exe，单文件版不受这个影响。
   某些杀毒软件会误报 PyInstaller 打包的程序，请放行。

Q: 区域完成度和我游戏里看到的不一样？
A: 先确认「严格 / 宽松」口径；再看该区域是否已导入房间数据。
   模组区域没导入时，完成度只按官方房间算。
   v{version} 修正过一版分母口径（此前会漏算 DLC 与模组补丁层的房间），
   所以同一存档的百分比可能比旧版略低 —— 那是把漏算的房间补回来了。

Q: 房间卡右侧写着「（未知）」或「本层画布没有对应出口格」？
A: 前者表示那个管道口确实没有连接目标（游戏里也是断开的）；
   后者表示房间文件里少画了这个出口格（模组数据不全）。编号本身仍然成立。

Q: 提示「配置来自更新版本的程序，本次只读」？
A: 用旧版程序打开了新版配置。换回新版程序即可，配置不会被覆盖。

Q: 想恢复默认设置？
A: 关闭程序，删除 config.json，重新启动即可。
